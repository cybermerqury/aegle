# Non-Binary LDPC

This crate implements non-binary LDPC error correction.
It implements the basic arithmetic on finite fields that are needed in order to implement the
decoder as described by [Davey and MacKay](<https://ieeexplore.ieee.org/document/706440>)

To build the documentation with inline $\KaTeX$ rendering run:

```custom,{.language-shell}
RUSTDOCFLAG="--html-in-header katex.html" cargo doc --no-deps
```
